## 🧠 About Project
This is a **full AI-based video recommendation system** similar to YouTube/Netflix basic algorithm.

The system tracks user behavior and suggests videos based on:
- Watch history  
- Interest category  
- Activity tracking  
- Smart recommendation logic  

It learns what user watches more and pushes similar content.

## 📸 How it works
1. User logs into system  
2. Watches videos  
3. System stores interest  
4. AI detects favorite category  
5. Suggests similar content
